# web application to train on chess openings.


## How to install

* `git clone` this repo
* `cd` to the folder named after the repo
* [install the `uv` tool if not present on your OS]
* `uv sync`

## How to run (once installed)

* go to the folder named after the repo
* `cd src`
* `uv run -- flask run -p 3000`

Then open a browser and access `http://localhost:3000/`


## Dev information 

* We use the flask framework for this app.
